# JSONPlaceholder API Explorer

A beginner Python project demonstrating GET and POST requests using the
JSONPlaceholder REST API.

## Features

- Retrieves all users
- Retrieves posts by user #3
- Retrieves comments on post #1
- Simulates creating a new post
- Displays HTTP status codes and item counts
